# Календарь звонков

Сервис бронирования времени: владелец календаря публикует типы встреч, гость без регистрации бронирует свободный слот.

## Language

**Owner**:
Владелец календаря — единственный заранее заданный человек, который публикует Meeting type и просматривает расписание.
_Avoid_: Администратор, пользователь

**Guest**:
Человек без регистрации, который выбирает тип встречи и бронирует свободное время.
_Avoid_: Клиент, пользователь, посетитель

**Meeting type**:
Публикуемое владельцем описание встречи — название, описание и длительность; гость выбирает его как повод для записи.
_Avoid_: Тип события, событие, услуга

**Booking**:
Забронированный гостем интервал времени для выбранного типа встречи.
_Avoid_: Запись, резерв, слот

**Slot**:
Потенциальное начало Booking на сетке стартов внутри Working hours; вычисляемый вариант, а не хранимая сущность.
_Avoid_: Свободное время, ячейка

**Working hours**:
Интервал внутри рабочего дня владельца, в который Booking должен поместиться целиком.
_Avoid_: Часы работы, расписание

**Booking window**:
Промежуток вперёд от текущего дня, в пределах которого гость может создать Booking.
_Avoid_: Окно записи, горизонт планирования
